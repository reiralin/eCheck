系統總覽

六大元件 · 雙業務流程共用同一基礎設施

👤
門市稽核員端
  • 開啟 BPM → 點選「eCheck 巡檢」
  • 以 BPM 帳號自動完成身份驗證
  • 選擇門市、版次，填寫巡檢表單
  • 拍照上傳（Base64 壓縮，最大 1600px）
  • 簽名後送出，自動產生 PDF 報告
  • 支援斷網草稿自動儲存
🏢
BPM Agentflow
  • 統一身份驗證（Tomcat Session）
  • proxyToGAS.jsp：代理所有 GAS 呼叫
  • 保管 HMAC 金鑰，前端不接觸機密
  • BPM Script Task 觸發版次匯入
  • 提供 /ext-2.0.2/userinfo 取得部門資訊
⚙️
Google Apps Script
  • 唯一 HTTP 入口：doPost（API）+ doGet（UI）
  • HMAC-SHA256 Token 驗證（時間窗 120s）
  • 17 個 Action 處理業務邏輯
  • 雙路徑分流：fs（食安）/ bd（品牌評比）
  • LockService 防止並發寫入衝突
🤖
Gemini AI 整合
  • 缺失文字分類（規則優先 → AI 補充）
  • 缺失嚴重度分析與改善建議
  • 月度關鍵字萃取（Top 25）
  • 照片異常辨識（aiAnalyzeImage）
  • 每日配額控制（預設 18 次 / 天）
  • 1 小時 Cache 避免重複呼叫
📊
Google Sheets（資料庫）
  • 食安表（FS）：巡檢版次 / 巡檢回應 / 缺失明細
  • 評比表（BD）：版次 / 回應 / 缺失 / 統計
  • 共用：門市座標 / AI缺失分析 / 月度關鍵字
  • ScriptProperties 保管敏感設定
📈
BI 儀表板
  • 嵌入 BPM 流程作業（iframe）
  • 全台門市地圖視覺化
  • 雷達圖八維度門市評分
  • 缺失佔比 / 風險排行 / 趨勢分析
  • 支援 FS + BD 雙模式切換
🗺️

GAS API 功能清單

17 個 Action · Code.js doPost 路由派遣

Action 功能說明 讀/寫 資料表 類型
getSystemStatus取得試算表基本狀態（最後更新時間、版本數量等）Read巡檢版次 / 巡檢回應FSBD

getVersionList取得可用版次清單（含狀態、發佈日期）Read巡檢版次FSBD
getChecklistByVersion依版次 ID 取得完整題目 JSONRead巡檢版次FSBD
createVersion手動建立新版次（管理員操作）Write巡檢版次FSBD
importVersionFromExcel解析 Base64 XLSX，批次寫入版次與題目Write巡檢版次 / 稽核LogFSBD
getStoreList取得所有門市清單含 GPS 座標Read門市座標共用
saveResponse儲存一份巡檢回應，含缺失明細與 GPS 定位Write巡檢回應 / 缺失明細FSBD
uploadPhotoBase64 圖片上傳至 Google Drive，回傳 fileIdWriteGoogle Drive共用
generateReportGoogle Docs 套版 → 轉 PDF → Drive 儲存 → Email 通知WriteDrive / 巡檢回應FSBD
getResponsesAll取得所有巡檢回應（BI 儀表板用）Read巡檢回應FSBD
getDefectsAll取得所有缺失明細（BI 雷達圖 / 缺失佔比）Read缺失明細FSBD
getMonthlyKeywords取得月度缺失關鍵字 Top 25Read月度關鍵字AI
getAIRadarData取得 AI 分析後的雷達圖各維度得分ReadAI缺失分析AI
getAIDefectAnalysis取得指定門市/版次的 AI 缺失分析詳情ReadAI缺失分析AI
warmUpAuth預熱 GAS 授權（解決冷啟動延遲）Read試算表 ID 驗證系統
doGet（獨立）瀏覽器直接訪問時回傳說明頁或 403 拒絕頁Read—系統

🤖 Gemini AI 內部函式

callGemini呼叫 Gemini API，支援重試 / throttle
aiAnalyzeDefect分析單筆缺失：分類 + 嚴重度 + 建議
ruleClassify規則優先分類（信心 < 3 才呼叫 AI）
aiExtractMonthlyKeywords月度缺失關鍵字萃取 Top 25
aiMonthlySummary彙整月度統計，產生摘要文字
aiAnalyzeImage照片異常 AI 辨識（Base64 輸入）
aiProcessResponse回應儲存後的 AI 全流程處理入口

🔒 安全與輔助函式

_validateTokenProduction HMAC-SHA256 驗證（doGet）
_validateTokenWithDebugDebug 版驗證，回傳詳細失敗原因
_getSSIDByType依 type 回傳正確試算表 ID
_newVersionId產生版次 ID：V+yyyyMMddHHmmss
_newResponseId產生回應 UUID
initSpreadsheetByType初次部署時建立所有分頁與標題列
_repairNoFields修復缺少「No」欄位的舊版資料
